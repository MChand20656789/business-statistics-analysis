# business-statistics-analysis

## Objective

The project applied statistical analysis to a transactional sales dataset containing 400 customer transactions recorded from March through June 2013. The analysis examined relationships and differences across transaction timing, customer demographics, geographic region, payment method, payment amount, and items purchased.

## Tools & Methods

Microsoft Excel
Descriptive statistics
Sample statistics
Hypothesis testing
Z-statistics
P-values
Data analysis and interpretation
Data visualization

## Business Questions

The analysis used statistical methods to answer questions about customer purchasing behavior, transaction characteristics, and differences across demographic and business categories.
